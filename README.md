# 一刻鯨選 App 模擬

使用 HTML、CSS、JavaScript 製作，依使用者提供的 App 截圖逐批還原。

## 啟動

先執行 `npm install`，再執行 `npm run dev`，瀏覽 http://localhost:4173 。

## 已可操作

- 首頁橫滑列表、分類、搜尋與排序。
- 通知與已讀狀態、公告內容。
- 設定、登入方式面板、下載管理、外觀及 App 內服務條款。
- 課程簡介與目錄、獨立展開、收藏、文稿、下載進度、mini player。
- 購買頁、紅包折抵、模擬兌換、贈送確認與示範代碼。
- 我聽：購買、租借、訂閱、收藏與閱聽紀錄。

## 模擬範圍

沒有串接會員驗證、真實點數、付款、贈送兌換或實際音訊。下載與播放為前端狀態模擬；示範購買只更新本機紀錄。未提供的課程集數使用標記為「示範」的單元補齊。租借與訂閱目前呈現空白內容狀態。資料保存在此瀏覽器的 localStorage，與正式服務無關。

詳細產品範圍與每批驗證記錄見 PRODUCT.md、design-qa.md。

## 紅包狀態預覽

- 一般購買選券：首頁點課程 → 購買 → 使用紅包折抵。
- 無紅包：http://localhost:4173/?couponDemo=empty#coupons
- 可贈送紅包：http://localhost:4173/?couponDemo=gift#coupons

兩個預覽使用各自獨立的本機示範資料，不影響一般紅包錢包。一般折價券只可選擇一張，折抵不超過課程價格；確認示範兌換後將標記該券為已使用。
